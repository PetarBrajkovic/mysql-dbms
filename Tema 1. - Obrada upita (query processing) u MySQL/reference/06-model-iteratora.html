Model iteratora i pipeline operatora

Sve što treba za čitanje jednog FORMAT=TREE stabla: interfejs, preslikavanje ispisa u klase, šta se meri i ko blokira pipeline.

1 · Interfejs

RowIteratorOsnovna klasa, sql/iterators/row_iterator.h. Iterator sme da čita iz drugog iteratora, pa se od njih gradi stablo.
Init()Inicijalizacija ili ponovna inicijalizacija. Uvek se poziva pre prvog Read(). Ponovni poziv premotava iterator.
Read()Čita jednu torku. Vraća 0 (u redu), -1 (nema više), 1 (greška).
UnlockRow()Otpušta zaključavanje nad torkom koja je pročitana pa odbačena.
bafer torkeTorka se ne vraća kao rezultat funkcije nego se upisuje u table->records[0].
unique_ptr<RowIterator> iterator(new ...);
if (iterator->Init())
  return true;
while (iterator->Read() == 0) {
  ...
}

2 · Ispis u klasu

Tekst se generiše u explain_access_path.cc, iterator se pravi u access_path.cc; obe datoteke granaju po istom path->type.

Table scan on …TableScanIterator
Index scan on …, Covering index scan on …IndexScanIterator<false>; <true> pri čitanju unatrag
Index lookup on …, Covering index lookup on …RefIterator<false>
Single-row index lookup on …EQRefIterator
Index range scan on …IndexRangeScanIterator
Filter: …FilterIterator
Sort: …SortingIterator
Limit: N row(s)LimitOffsetIterator
Group aggregate: …, Aggregate: …AggregateIterator
Nested loop <tip> joinNestedLoopIterator
Inner hash join …HashJoinIterator
Stream resultsStreamingIterator
Materialize, Materialize CTE …gradnja privremene tabele, slučaj MATERIALIZE
Hashnije iterator — natpis na grani ka ulazu koji se hešira. Jedini red bez brojeva uz sebe.

3 · Čitanje brojeva

-> Covering index lookup on r using idx_fk_customer_id (customer_id=c.customer_id)
     (cost=1.07 rows=27.4) (actual time=0.0058..0.00727 rows=26.8 loops=584)
        procena  ^^^^^^^^^            prvo^^  ^^poslednje   stvarno^^  ^^Init()
loopsBroj poziva Init(). Kod ugnježdene petlje: jednom po torki spoljašnjeg ulaza.
rows (u drugoj zagradi)Stvarni broj torki, prosek po ponavljanju — zato sme da bude decimalan. Ukupno = rows puta loops.
actual time=a..ba je vreme do prve torke, b do poslednje, u milisekundama, prosečno po ponavljanju.
uvlačenjeDublje uvučen red je dete. Kontrola ide nadole (Read()), torke nagore, po jedna.

4 · Ko blokira pipeline

prvo << poslednjepipeline operator — torke izlaze kako pristižu
prvo = poslednjeblokirajući operator — ništa nije izašlo dok sve nije ušlo
pipelineTable scan, Index scan, Index lookup, Filter, Limit, Nested loop join, Stream results
blokiraSort, Materialize, Aggregate using temporary table, faza gradnje hash spoja (ulaz pod natpisom Hash)
Posledica koju vredi pamtiti Sken ne zna ništa o LIMIT-u; on prosto prestaje da bude pozivan. Zato isti sken uz LIMIT 10 pročita deset torki, a čim se iznad njega nađe Sort, pročita celu tabelu.

5 · Odakle iteratori dolaze

AccessPathC++ struktura, plan. „Correspond 1:1 to iterators… plus some information that is only needed during planning, such as costs."
CreateIteratorFromAccessPath()Prevodi stablo AccessPath struktura u stablo iteratora, granajući se po path->type.
pristupni putPojam iz poglavlja 1 i 3, način dolaska do torki jedne tabele. Nije isto što i AccessPath.
join_executionPrazna faza traga optimizatora, jer se u izvršavanju ne donosi nijedna odluka vredna beleženja.
