Dva nivoa (03_Optimizacija str. 2)

Logički (viši)

  • Preformuliše izraz RA → ekvivalentan, brži.
  • Menja oblik, čuva rezultat.
  • Citat: 03 str. 2.

Fizički (niži)

  • Bira algoritam + pristupni put po operatoru.
  • Sken vs. indeks; spoj ugnježdenim petljama / sort-merge / heš.
  • „Nema univerzalno superiorne tehnike“ — 02 str. 4.

Recept (03_Optimizacija str. 3)

  1. Napiši prošireni upit relacione algebre  →  logički
  2. Izaberi algoritme najmanje cene za međurezultate  →  fizički
  3. Izvrši ih, proizvedi rezultat  →  izvršavanje

Rečenica koja opravdava ceo rad

03_Optimizacija str. 2 Jedan SQL upit → više ekvivalentnih planova veoma različite cene; DBMS mora da pretražuje i bira najefikasniji. Sve posle Poglavlja 1 pokazuje kako MySQL taj izbor donosi i izvršava.
