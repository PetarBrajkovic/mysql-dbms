Group Replication: niz, provera saglasnosti, kvorum, nivoi

Sažetak lekcije 05. MySQL 8.4.11, naša topologija 3307/3308/3309.

Lanac komitovanja

T executes locally (no coordination, local row locks only)
COMMIT -> write-set {PKs of changed rows} sent to the group
       -> XCom (Paxos variant): majority places T in ONE total order, same on every member
       -> every member: "did an earlier T', unseen by T, touch the same row?"
             no  -> commit everywhere        yes -> abort everywhere (first in order wins)
       -> OK to client                        // DECISION: a majority has T
each member's applier applies T later      // VISIBILITY on that member
