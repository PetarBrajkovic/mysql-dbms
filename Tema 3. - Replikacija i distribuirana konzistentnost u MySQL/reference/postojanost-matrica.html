Dvofazno komitovanje (internal XA)

COMMIT(T):
  1  redo.append(T, PREPARED);   redo.fsync()     // phase 1: prepare
         ⚡ crash A  →  binlog does not contain T
  2  binlog.append(T);           binlog.fsync()   // phase 2: DECISION POINT
         ⚡ crash B  →  binlog contains T
  3  redo.append(T, COMMITTED)                    // records the decision
  4  return "OK" to client

RECOVER():                                        // on restart after a crash
  for each T marked PREPARED in redo:
      if binlog.contains(T):  commit(T)           // crash B
      else:                   rollback(T)         // crash A

Pravilo oporavka: pripremljen T koji je u binarnom logu → commit; koji nije → rollback. Binarni log odlučuje jer je on jedino što replike dobijaju (K3).
