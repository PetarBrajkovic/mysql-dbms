Semisinhrona potvrda: šta znači, gde se čeka, kada ćuti

Sažetak lekcije 04. MySQL 8.4.11, naša topologija 3307/3308/3309.

Potvrda

značinit prijema je upisala T u relay log i uradila fsync (19.4.10)
ne značida je T primenjena ili vidljiva na replici
broj potvrdarpl_semi_sync_source_wait_for_replica_count, podrazumevano 1
instalacijaINSTALL PLUGIN rpl_semi_sync_source SONAME 'semisync_source.dll'; na replici rpl_semi_sync_replica / semisync_replica.dll. Dodatak (plugin), ne komponenta; *_enabled je posle svakog pokretanja OFF

Niz komitovanja i dve tačke čekanja

COMMIT(T) on the source:
  1  redo: prepare
  2  binlog: write + fsync        // DECISION: after a crash, recovery commits T
        AFTER_SYNC waits here     // (default) nobody sees T yet
  3  InnoDB: commit               // VISIBILITY: other sessions read T from now on
        AFTER_COMMIT waits here   // others see T, no replica has it yet
  4  return "OK" to client

Izmereno (potvrda zadržana, niti prijema zaustavljene)

prozor vidljivostiAFTER_SYNC 0 ms · AFTER_COMMIT 3005 ms (timeout 3000 ms)
pad + failover, AFTER_COMMITB je videla red; A dobija grešku veze; na novom izvoru reda nema
pad + failover, AFTER_SYNCniko nije video red; A dobija grešku veze; na novom izvoru reda nema
stari izvor posle oporavkau oba režima ima red (višak GTID sa svojim UUID-om)
povezan kao replika novogYes/Yes, 0 grešaka, Seconds_Behind_Source 0, CHECKSUM se razlikuje

Pravila

failover / switchoverotkaz, ništa nije predato / planirano, replika primi sve pre zamene
stari izvor„must be discarded“ (priručnik); MySQL to ne sprovodi. Greška 1885 važi samo za GTID-ove sa UUID-om novog izvora
provera viškaGTID_SUBTRACT(gtid_old, @@gtid_executed) na novom izvoru
istek vremenarpl_semi_sync_source_timeout = 10000 ms: OK bez upozorenja → asinhrono → samo se vraća kad replika sustigne

…_yes_txprestaje da raste
…_wait_sessionssesije koje upravo čekaju

Cena

t(commit) ≈ t(fsync binlog) + t(fsync redo) + t(round trip to the replica)
loopback, 1/1764 → 978 µs, u granicama šuma
loopback, 0/261 → 124 µs, +103 %
replika na 1000 kmpovratno putovanje ≥ ~10 ms (svetlost u vlaknu ~200 000 km/s)
pravilonijedan broj o ceni bez podešavanja postojanosti
